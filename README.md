# Portfólio — Henrique Leal

Portfólio profissional para apresentar projetos reais de sites, sistemas web, inteligência artificial e automações.

O site reúne trabalhos desenvolvidos para os segmentos imobiliário, educacional, automotivo, jurídico, refrigeração, marmoraria e serviços profissionais. A interface possui animações, apresentação responsiva e uma experiência móvel otimizada.

## Tecnologias

- React 19
- Vite 8
- Tailwind CSS
- Framer Motion
- Three.js e React Three Fiber

## Executar localmente

Requisitos: Node.js 20 ou superior e npm.

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run lint
npm run build
npm audit
```
